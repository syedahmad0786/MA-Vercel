## 1.2 Community Insights — What Makes a "Complete" Snapshot

### Sources: Facebook Groups, Reddit, Skool Communities, YouTube

The community consensus on what constitutes a **complete** snapshot centers around these **non-negotiable** elements:

#### Must-Have (Universally Expected)
1. **Lead Capture Funnel** — At minimum one opt-in page + thank you page
2. **Missed Call Text Back** — #1 most requested "quick win" automation
3. **Appointment Booking** — Calendar setup with confirmation + reminder sequence
4. **Basic CRM Pipeline** — At least a "New Lead → Contacted → Appointment Set → Won/Lost" pipeline
5. **Lead Nurture Sequence** — Multi-step SMS + email follow-up (minimum 5–7 touches)
6. **Review Request Automation** — Triggered after service completion or deal won
7. **Custom Values for Business Info** — So nothing is hardcoded
8. **Email & SMS Templates** — Pre-written with merge tags

#### Considered Premium / Advanced
1. **Database Reactivation Campaign** — Re-engage cold leads from existing contact lists
2. **Referral Request Workflow** — Automated ask for referrals after positive review
3. **No-Show Recovery** — Automated follow-up when appointments are missed
4. **Long-Term Nurture** — 12–24 month drip sequence (most agencies never build this)
5. **Upsell / Cross-Sell Flows** — Post-purchase automated offers
6. **Membership / Course Delivery** — Content access via GHL membership area
7. **Advanced Reporting Dashboard** — Custom widgets showing pipeline health, conversion rates, revenue
8. **Social Proof Automation** — Auto-collect and display testimonials
9. **Chat Widget + Conversation AI** — Automated chat responses
10. **Reputation Management Dashboard** — Review monitoring + AI auto-responses

#### What the Community Complains About
- Snapshots with hardcoded business names, phone numbers, and URLs
- Missing documentation / no setup guide
- Workflows that reference custom values that don't exist in the snapshot
- Overly complex workflows that are difficult to customize
- No naming conventions — impossible to tell what belongs to what
- Email/SMS copy that is too niche-specific to be adaptable

# PART 2 — SNAPSHOT PLANNING DOCUMENT

## Design Principles

### 1. Zero Hardcoded Specifics
Every business name, phone number, URL, address, email, tagline, or any business-specific detail MUST be replaced with a **Custom Value**. No exceptions.

### 2. Contact-Level Personalization via Custom Fields
Every contact-specific attribute (name, industry, source, interest, budget, etc.) MUST use a **Custom Field** with merge tag references.

### 3. Merge Tag Everything
All email copy, SMS copy, funnel text, and workflow messages MUST use `{{custom_values.xxx}}` and `{{contact.xxx}}` merge tags. Zero hardcoded business specifics in any copy.

### 4. Consistent Naming Convention
Every asset follows this format:

```
[AiXCEL] - {Category} - {Descriptor} - {Qualifier}
```

**Examples:**
- `[AiXCEL] - Workflow - Lead Nurture - Day 1 SMS`
- `[AiXCEL] - Pipeline - Sales`
- `[AiXCEL] - Funnel - Lead Capture`
- `[AiXCEL] - Email - Appointment Reminder - 24h`
- `[AiXCEL] - Form - Contact Inquiry`
- `[AiXCEL] - Calendar - Discovery Call`
- `[AiXCEL] - Tag - Status: New Lead`
- `[AiXCEL] - SmartList - Hot Leads`
- `[AiXCEL] - Dashboard - Main Overview`

### 5. Phase-Based Delivery
Assets are categorized into MVP (Phase 1), Growth (Phase 2), and Power User (Phase 3) for staged deployment.

### 6. Industry-Agnostic by Default
All copy, workflows, and assets are designed to work for ANY business type. Niche-specific language is avoided — placeholders like `{{custom_values.service_name}}` and `{{custom_values.offer_description}}` are used instead.

## IMPLEMENTATION NOTES

### Snapshot Build Order (Recommended)

1. **Custom Values** — Create all custom values first (they're referenced by everything else)
2. **Custom Fields** — Create all contact and opportunity custom fields
3. **Tags** — Create all tags
4. **Pipelines** — Build pipeline stages
5. **Calendars** — Set up booking calendars
6. **Forms & Surveys** — Build all forms mapping to custom fields
7. **Funnels** — Create landing pages with forms/calendars embedded
8. **Email & SMS Templates** — Write all templates with merge tags
9. **Workflows** — Build automations (they reference all of the above)
10. **Smart Lists** — Create filtered views
11. **Dashboards** — Set up reporting widgets
12. **Chat Widget** — Configure and brand
13. **Test Everything** — Run through every workflow with test contacts
14. **Save Snapshot** — Create snapshot from the completed subaccount

### Quality Checklist Before Snapshot Release

- [ ] Zero hardcoded business names, phones, emails, or URLs
- [ ] All merge tags resolve correctly (no broken `{{}}` references)
- [ ] Every workflow trigger fires correctly
- [ ] Appointment confirmation + reminders work end-to-end
- [ ] Missed call text back fires within 2 minutes
- [ ] Review request sends after deal marked Won
- [ ] All forms map to correct custom fields
- [ ] Funnels are mobile-responsive
- [ ] Email templates render correctly in major email clients
- [ ] SMS messages are under 160 characters where possible
- [ ] All tags are applied/removed correctly by workflows
- [ ] Pipeline stages have clear entry/exit criteria
- [ ] Dashboard widgets display accurate data
- [ ] Documentation / setup guide is included
